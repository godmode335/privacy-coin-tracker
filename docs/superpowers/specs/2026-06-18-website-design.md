# Privacy Coin Tracker — Веб-сайт (спека)

**Дата:** 2026-06-18
**Статус:** утверждён к реализации
**Связано:** [[2026-06-17-privacy-coin-portfolio-tracker-design]] (десктоп-приложение)

## 1. Цель

Сайт-маркетинговая поверхность для десктоп-приложения Privacy Coin Tracker.
Главная и единственная KPI-цель — **максимум органических установок без
платного бюджета**: высокие позиции в поиске по целевым ключевикам +
конверсия трафика в скачивания `.exe`.

**Жёсткое требование:** на первом экране лендинга — заметная рабочая кнопка
«Download for Windows», ведущая напрямую на скачивание `.exe`.

## 2. Ключевые решения

| Решение | Выбор |
|---|---|
| Тип сайта | Контентно-ориентированный статический сайт (лендинг + блог), не SPA |
| Стек | Astro + content collections (Markdown/MDX) |
| Хостинг сайта | Cloudflare Pages (бесплатно, CDN), авто-деплой из GitHub |
| Домен | Кастомный (~$10/год), покупает владелец; архитектура domain-ready |
| Хостинг `.exe` | GitHub Releases (ссылка `/releases/latest/download/...`) |
| Аналитика | Cloudflare Web Analytics + Google Search Console |
| Расположение | Папка `website/` в том же репозитории |
| Веб-демо трекера | Вне этого этапа (YAGNI), задел под Astro-island сохраняем |

## 3. Обоснование (почему так)

- SPA-трекер плохо индексируется (тонкий контент, медленный рендер) — это
  антипаттерн для органики. Выигрывают статические, быстрые, контентные страницы.
- Единственный бесплатный масштабируемый рычаг органики — **контент (статьи)**
  под поисковые запросы + быстрый лендинг с явным CTA.
- USP-моат: крупные трекеры облачные и с аккаунтами; мы — приватный, локальный,
  без аккаунта. Аудитория, ищущая «private/offline/no-account tracker», —
  недообслужена, низкая конкуренция, высокая конверсия.

## 4. Структура страниц (IA)

```
/                 Лендинг: hero + ГЛАВНАЯ кнопка Download (первый экран),
                  фичи, «почему приватный», скриншоты, FAQ, повторный CTA.
/download         Страница загрузки: кнопка, версия, размер, требования,
                  инструкция по SmartScreen, SHA-256 для проверки.
/blog             Индекс статей.
/blog/<slug>      Статьи под кластеры ключевиков.
/privacy          Политика приватности (= маркетинг «мы не собираем данные»).
/about            О проекте / опенсорс, ссылка на GitHub.
```

Принципы: кнопка скачивания видна без скролла и продублирована внизу; каждая
статья ссылается на `/download`; человекочитаемые URL (`/blog/zcash-vs-monero`).

## 5. SEO-механика

- **Per-page мета:** уникальные `<title>` и `meta description` под целевой ключ;
  Open Graph + Twitter Card.
- **JSON-LD:** `SoftwareApplication` (лендинг), `BlogPosting` (статьи),
  `BreadcrumbList`, `FAQPage` (FAQ).
- **Технический фундамент:** авто `sitemap.xml`, `robots.txt`, canonical,
  H1/H2 под запросы, alt у изображений.
- **Скорость:** статика на CDN, Astro `<Image>` → WebP/AVIF, нулевой JS на
  контентных страницах по умолчанию; цель — зелёный Core Web Vitals.
- **Перелинковка:** каждая статья → CTA `/download`; связанные статьи между собой.

## 6. Технологии и хостинг

- **Astro** + **content collections**: статьи в Markdown/MDX с типизированным
  frontmatter (`title`, `description`, `keywords`, `date`, `ogImage`,
  `draft`).
- **Cloudflare Pages**: авто-деплой при push; кастомный домен.
- **Структура репозитория:** папка `website/` (Astro) рядом с приложением;
  не пересекается со сборкой Tauri.
- **Кнопка скачивания** → `https://github.com/<owner>/privacy-coin-tracker/releases/latest/download/<asset>`
  (стабильная ссылка на последний релиз).
- **Релиз `.exe`:** загрузить NSIS-инсталлятор как asset GitHub Release.

## 7. Контент-план (старт)

Лендинг-копирайт под privacy-angle + 5 стартовых статей (каждая 800–1500 слов,
с CTA на скачивание):
1. `best-privacy-coins-2026` — широкий информационный трафик.
2. `zcash-vs-monero` — сравнение, высокий объём.
3. `how-to-track-zcash-privately` — прямой intent на продукт.
4. `are-online-crypto-trackers-safe` — боль аудитории → USP.
5. `offline-crypto-portfolio-tracker-guide` — long-tail, низкая конкуренция.

## 8. Аналитика и измерение

- **Cloudflare Web Analytics** — трафик и Core Web Vitals, без кук.
- **Google Search Console** — позиции, запросы, индексация, отправка sitemap.
- Без сторонних трекеров/кук (согласуется с privacy-брендом).

## 9. Тестирование / приёмка

- Сборка Astro проходит (`astro build`), `astro check` без ошибок типов.
- Lighthouse SEO и Performance — зелёные (≥90) на лендинге и статье.
- `sitemap.xml` и `robots.txt` генерируются и содержат все страницы.
- Кнопка Download ведёт на реальный, скачиваемый файл (GitHub Releases).
- Все страницы имеют уникальные title/description и валидный JSON-LD.

## 10. За рамками этапа (будущее)

- Интерактивное веб-демо трекера (IndexedDB) как Astro-island.
- Расширение блога, программный набор статей под long-tail.
- Локализация (RU/EN) при необходимости.
- Кастомные OG-изображения под каждую статью.
